# Mondrian Parte A

Comecei por utilizar a function setup, que serve para preparar a área de trabalho, e em seguida o createCanvas(917,899) para definir a área onde iria recriar a pintura, sendo os 917 píxeis a largura e 899 a altura. Usei também o noLoop() para indicar que o desenho deve ser executado só uma vez, impedindo que a function draw() se repita.

Para construir os elementos da pintura, como as linhas e os retângulos, utilizei a function draw(). No programa Illustrator, medi as coordenadas das linhas e dos retângulos e registei os códigos RGB de cada cor presente na obra, o que facilitou muito para converter o posicionamento dos elementos e as cores para o código p5.js. 
Usei o background(225, 229, 223) para definir a cor do fundo, RGB para um cinzento claro, e o stroke(20) e o strokeWeight(10) para definir, respetivamente, a cor e a espessura do traço das linhas. Para traçar cada linha entre dois pontos usei o line, indicados por pares de coordenadas, na forma line(x1, y1, x2, y2), e com o qual construí a grelha de linhas horizontais e verticais.

Depois das linhas, desenhei os três retângulos da pintura, cada um com a sua cor. Para cada um utilizei o fill(), que define a cor de preenchimento através do código RGB (por exemplo fill(231, 6, 4)), e o rect() que desenha o retângulo a partir do canto superior esquerdo. Assim, rect(422, 586, 284, 250) representa um retângulo definido pelas coordenadas x e y seguidas pela sua largura e altura.
Com todos os elementos da pintura codificados, passei à textura. Escolhi na web uma imagem em jpeg. com textura de papel e guardei-a na pasta do trabalho com um nome á escolha. 

Na function setup, aseguir ao noLoop(), usei o loadImage, que carrega a imagem a partir do nome do ficheiro, e a 'textura.jpg' que é a imagem em si que se quer que seja carregada (o ficheiro no sketch tem de estar com o mesmo nome que o ficheiro na pasta para que seja carregada corretamente). Em seguida, usei o img => texturaImg = img, uma função que, quando a imagem é carregada com sucesso, a recebe e a guarda na variável texturaImg, permitindo usá-la mais tarde na função draw. Posteriormente, o redraw() repete o desenho já com a textura disponivel, e o () => console.error('Failed to load image') mostra uma mensagem de erro na consola do navegador caso o carregamento da imagem falhe, o que ajuda a identificar problemas como o nome do ficheiro incorreto entre outros. 

Por fim na function draw, depois do código das linhas e retângulos, para que a textura fique por cima de todos os elementos, usei o if (texturaImg), que verifica se a imagem já foi carregada antes de a desenhar, e o push(), para que as alterações feitas até ao pop() não interfiram com o resto do desenho. Dentro do push() do e pop(), apliquei o blendMode(MULTIPLY) que define a forma como a imagem da textura se combina com a da pintura, as zonas mais claras da textura deixam as cores intactas e as zonas escuras escurecem-nas. O tint(255, 125) ajusta a imagem antes de ser aplicada, sendo que o valor 255 mantém as cores da textura e o valor 125, numa escala de 0 a 255, deixa-a com cerca de metade da opacidade. Por último, o image(texturaImg, 0, 0, width, height); define a posição e as medidas da textura, que cobre toda a área de trabalho.
