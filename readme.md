# Mondrian Parte A

Comecei por utilizar a function setup (que serve para preparar a área de trabalho) e em seguida o createCanvas(917,899) para definir a área onde iria recrear a pintura, sendo os 917 pixeis a largura e 899 a altura da área de trabalho, e noLoop() para indicar que o desenho deve ser executado só uma vez, impedindo que a function draw() se repita.

Para fazer os elementos da pintura como as linhas e os quadrados, utilizei a function draw(). Tendo em conta que, no programa Ilustrator, tirei as coordenadas ás linhas e quadrados e registei os códigos RGB de cada cor presente na obra, foi-me muito mais fácil converter o posicionamento dos elementos e as cores para o código p5.js. 
Usei o background(225, 229, 223) para definir a cor do fundo, sendo este o código RGB para o cinzento claro e stroke(20) e strokeWeight(10) para definir a cor e a espessura do traço respetivamente das linhas que iria escrever posteriormente. Usei a line para traçar uma linha entre dois pontos, indicados por pares de coordenadas, que foram usadas para construir a grelha de linhas horizontais e verticais. Desta forma ficaria line(x1, y1, x2, y2).
Depois de fazer as linhas comecei a fazer os quadrados da pintura. Para cada quadrado, que no caso são 3 cada um com uma cor diferente, utilizei o fill(231, 6, 4) para colorir cada quadrado com o código RGB da cor e rect(422, 586, 284, 250) para desenhar o retângulo a partir do canto superior esquerdo. Deste modo, o código rect(422, 586, 284, 250) representa um retângulo definido pelas coordenadas x e y, seguidas pela sua largura e altura, respetivamente.
Depois de ter todos os elementos da pintura codificados, comecei a desenvolver a textura. Escolhi uma imagem em jpeg. da web com uma textura de papel e coloquei na pasta do trabalho com um nome á escolha. 

Na function setup, depois do noLoop(), usei a loadImage que tem como função carregar a imagem, e a 'textura.jpg' que é a imagem em si que se quer que seja carregada (o ficheiro no sketch tem de estar com o mesmo nome que o ficheiro na pasta para que seja carregada corretamente). Em seguida, usei o img => texturaImg = img, que serve para quando a imagem for carregada com sucesso, uma pequena função recebe-a e guarda-a na variável texturaImg, o que permite usá-la mais tarde na função draw. Posteriormente, usei o redraw() que repete o desenho já com a textura disponivel e o () => console.error('Failed to load image') que mostra uma mensagem de erro na consola do navegador caso o carregamento da imagem falhar, permitindo identificar problemas como o nome do ficheiro incorreto entre outros. 

Por fim na function draw, e por baixo dos códigos das linhas e quadrados, para que fique por cima de tudo o resto e seja aplicado sobre os elementos da pintura, usei o if (texturaImg) para verificar se a imagem da textura já foi carregada antes de a desenhar e o push() para que todas as alterações até ao pop() não interfiram com o resto. Dentro do push() e pop(), apliquei o blendMode(MULTIPLY) que define como a imagem da textura se combina com a que já lá está da pintura, as zonas mais claras da textura deixam as cores intactas e as zonas escuras escurecem-nas, apliquei o tint(255, 125) para ajustar a imagem antes que seja aplicada, sendo que o valor 255 mantém as cores da textura como são e o valor 125, numa escala de 0 a 255, deixa a textura com metade da opacidade e utilizei o image(texturaImg, 0, 0, width, height); para determindar as medidas e posição da textura na imagem.
