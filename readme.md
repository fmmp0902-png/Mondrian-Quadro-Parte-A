# Mondrian Parte A

Comecei por utilizar a function setup (que serve para preparar a área de trabalho) e em seguida o createCanvas(917,899) para definir a área onde iria recrear a pintura, sendo os 917 pixeis a largura e 899 a altura da área de trabalho, e noLoop() para indicar que o desenho deve ser executado só uma vez, impedindo que a function draw() se repita.
Para fazer os elementos da pintura como as linhas e os quadrados, utilizei a function draw(). Tendo em canto que, no programa Ilustrator, tirei as coordenadas ás linhas e quadrados e registei os códigos RGB de cada cor presente na obra, foi-me muito mais fácil converter o posicionamento dos elementos e as cores para o código p5.js. 
Usei o background(225, 229, 223) para definir a cor do fundo, sendo este o código RGB para o cinzento claro e stroke(20) e strokeWeight(10) para definir a cor e a espessura do traço respetivamente das linhas que iria escrever posteriormente. Usei a line para traçar uma linha entre dois pontos, indicados por pares de coordenadas, que foram usadas para construir a grelha de linhas horizontais e verticais
